# RevOps Playbooks

## Pipeline Coverage Recovery Playbook

Use this when weighted coverage is below target.

1. Segment open pipeline by stage and owner.
2. Flag high-value deals with no recent activity.
3. Verify close dates and probability hygiene for late-stage deals.
4. Push net-new pipeline creation targets by rep and territory.
5. Re-forecast after hygiene fixes to measure improvement.

Recommended manager prompts:

- Which deals in commit have not moved in 14 days?
- Which reps are below 2x weighted coverage and why?
- Which stage has the highest volume but lowest conversion?

## Quota Risk Triage

Use this when reps are behind plan.

Risk signal pattern:

- Low attainment with low weighted coverage.
- Late-stage pipeline concentration in a small number of deals.
- Declining win rate over rolling periods.

Triage order:

1. Confirm quota, period, and territory alignment.
2. Validate pipeline quality before increasing activity goals.
3. Assign deal inspection actions for top at-risk opportunities.
4. Define weekly leading indicators (coverage, stage movement, meetings).
5. Escalate structural issues (territory, capacity, pricing) to RevOps.

## Deal Slip Reduction Playbook

Use this when overdue or slipping deals increase.

1. Build a slip list by expected close date and stage.
2. Require a next-step and owner for each slipped deal.
3. Remove stale close dates and re-stage low-confidence opportunities.
4. Track slip rate by rep, segment, and manager.
5. Add close-plan checkpoints for high-value deals.

Manager coaching questions:

- What changed since the last customer commitment?
- Is there a clear economic buyer and decision timeline?
- Is this deal still in the correct stage?

## Forecast Quality Guardrails

Use this when forecast variance is high.

1. Compare forecast categories against historical conversion rates.
2. Separate commit and upside in pipeline reviews.
3. Track forecast bias by team and manager.
4. Require evidence notes for large upside deals.
5. Use rolling backtests to monitor model drift.

## Compensation and Payout Review Checklist

Use this before finalizing payouts.

1. Reconcile payout totals to commission plus incentives.
2. Verify accelerator triggers against attainment thresholds.
3. Confirm bonus eligibility inputs (deals, quality, team conditions).
4. Audit plan assignment effective dates.
5. Produce exceptions report for manual review.

## Territory and Plan Governance Checks

Use this during monthly governance.

1. Check for reps without active plan assignments.
2. Check for territories without active rep coverage.
3. Compare quota load across territories for fairness.
4. Validate rule overlap and conflicting commission bands.
5. Review changes with effective dates and audit trail.
